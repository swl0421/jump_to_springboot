점프 투 스프링부트 3
================

프로젝트 목표
------------
본 프로젝트는 박응용 저 이지스퍼플리싱 사의 "Do it! 점프 투 스프링부트 3"을 참고하여 스프링 부트를 통한 게시판 개발, 배포 및 운영을 목적으로 하는 프로젝트 리포지터리이다.

스프링부트를 사용함뿐 아니라 깃허브를 통한 프로젝트 관리에 익숙해 짐을 부가 목표로 한다.

프로젝트 개발 환경
---------------
* OS: Windows 11 x64 및 Windows 10 x64
> 본 프로젝트는 노트북과 데스크탑, 총 두개의 기기에서 개발을 진행한다.
* IDE: IntelliJ IDEA Ultimate 25.06 및 26.06
> IDE 버전은 각각 노트북과 데스크탑에 대응된다.
* JDK: JDK SE 21.0.11
* Spring Boot: Spring Boot 3.5.16

프로젝트 진행 사항
---------------
### 2026.06.25

* 1-02 스프링 부트 개발 환경 준비하기
> * JDK 설치 및 IDE 설정: 처음엔 최신 JDK(26)을 설치하려 했으나, gradle 호환성 문제로 인해 JDK 21로 프로젝트를 진행하게 되었다. 또한, 교재에서는 STS IDE 환경을 사용하나, 이미 Ultimate License가 있는 Intellij IDEA로 프로젝트를 진행하게 되었다.
> * 2개 이상의 기기에서의 개발을 위한 Git 연동: 교재와는 무관한 내용이지만, 본가의 데스크탑과 노트북에서 개발을 하면서 프로젝트를 관리하기 위해 깃헙을 연동했다.
> * 프로젝트 생성: 스프링 부트 프로젝트를 생성했다.
* 1-03 스프링 부트 맛보기
> * 웹 서비스의 동작 구조: 클라이언트와 서버, IP주소와 포트에 대한 간단한 설명과 도식을 통해 구조를 이해했다.
> * 컨트롤러 만들기: HelloController 클래스를 생성하고, "Hello World!"를 출력하는 메서드를 생성했다.
* 1-04 스프링 부트 도구 설치하기
> * Spring Boot Devtools 설치: 서버 자동 재시작 등 여러 기능이 있는 Spring Boot Devtools를 설치하기 위해 build.gradle 파일에 종속성을 추가하고 IDE의 설정을 변경했다.
> * 롬북 설치: 롬북은 IntelliJ 최신 버전에 기본 플러그인으로 제공되나, 위와 마찬가지로 build.grade 파일에 종속성을 추가했다. 롬북은 Getter, Setter 메소드, 생성자 등 Java 개발을 진행할 때 필수적인 메소드 등을 Annotation 추가 만으로 만들어 주는 도구이다.
* 2-02 간단한 웹 프로그램 만들기
> * URL 매핑 및 컨트롤러 이해: 컨트롤러인 MainController 클래스를 만들고, URL 매핑을 통해 스프링 부트가 요청을 받아 메소드를 호출 할 수 있도록 하였다. 이 과정에서 매핑되지 않은 URL 호출을 통한 404에러, URL과 매핑된 메소드가 결괏값을 반환하지 않을 때 발생하는 500 에러를 확인했다.
* 2-03 JPA로 데이터베이스 사용하기 
> * ORM과 JPA: ORM은 SQL을 사용하지 않고도 데이터베이스를 관리 할 수 있는 도구이다. ORM을 통해 데이터베이스를 관리하면 DBMS의 종류와 관계 없이 일관된 JAVA 코드를 통해 관리 할 수 있게 되고 개발자가 달라도 일정한 쿼리를 작성 할 수 있게 되고 오류율이 줄어드는 장점이 존재한다. 
> JPA는 인터페이스 모음이고 이를 구현한 클래스로는 하이버네이트가 존재한다. 본 프로젝트도 하이버네이트를 통해 개발을 진행했다.
> * H2 데이터베이스 설치: build.grade 및 application.properties 파일에 종속성을 추가했다.
> * JPA 환경 설정: application.properties 파일에 종속성을 추가했다.
